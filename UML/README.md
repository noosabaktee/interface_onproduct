# Dokumentasi UML KMI CFD Simulation Platform

Dokumentasi UML dipisahkan berdasarkan jenis diagram agar lebih mudah dibaca, dirender, dan dimasukkan ke laporan.

| Dokumen | Isi |
| --- | --- |
| [use-case.md](use-case.md) | Use Case Diagram dengan satu aktor, yaitu Pengguna CFD. |
| [activity.md](activity.md) | Activity Diagram berbentuk swimlane dan dipisahkan per proses. |
| [sequence.md](sequence.md) | Sequence Diagram Boundary-Control-Entity dan dipisahkan per proses. |
| [class.md](class.md) | Class Diagram implementasi, dependency injection, service, model, dan modul fungsional. |
| [erd.md](erd.md) | ERD SQLite aktual, penyimpanan konseptual, dan rancangan pengembangan. |

Seluruh diagram menggunakan Mermaid. Gunakan preview Markdown yang mendukung Mermaid agar diagram tampil sebagai gambar.
